## Overview
TRON Tethes (UST) is an advanced TRC20 digital asset designed to provide a fast, secure, and scalable alternative for global peer-to-peer transactions and payments on the TRON blockchain. It aims to deliver a stable and efficient medium of exchange within the decentralized ecosystem.

## Smart Contract Architecture
The smart contract system is built using an upgradeable proxy pattern to ensure future-proofing and security. The architecture completely separates the contract state from the business logic.
